# Employee Attendance & Analytics API

Python 3.11+, FastAPI and MongoDB 6.0+. From this directory, install dependencies with `pip install -r requirements.txt`, set `MONGO_URI` and `MONGO_DB`, then run `uvicorn app.main:app --port 8000`. Indexes are created automatically at startup.

Implementation and remaining design notes are in `app/main.py`, `REVIEW.md`, and `DECISIONS.md`.
